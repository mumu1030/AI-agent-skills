# 代码分析检查清单

从代码中提取业务信息，用于撰写 PRD。按模块逐项检查，无法从代码推断的写入「开放问题」。

## 1. 模块边界

- [ ] 模块包含哪些页面/接口
- [ ] 模块入口（菜单项、路由、API 前缀）
- [ ] 与其他模块的跳转关系

## 2. 角色与权限

| 扫描位置 | 提取内容 |
|----------|----------|
| 路由守卫 | 未登录/无权限时的跳转与提示 |
| `v-if="hasRole"`、`permission` | 按钮/菜单可见性 |
| 后端 `@PreAuthorize`、`roles` | 接口级权限 |
| 页面内角色判断 | 不同角色看到的功能差异 |

输出：角色 | 可执行操作 | 限制

## 3. 功能清单

对每个页面/接口识别：

- [ ] 列表查询（筛选、排序、分页）
- [ ] 新增/创建
- [ ] 编辑/更新
- [ ] 删除（单条/批量）
- [ ] 详情查看
- [ ] 导出/导入
- [ ] 审批/状态变更
- [ ] 其他业务动作（分配、取消、退款等）

为每项分配 REQ-001、REQ-002…，标注 P0/P1/P2。

## 4. 页面与导航

提取 pages 对照表（内部使用，不写入 PRD 正文）：

| 路由/路径 | 中文页面名 | 来源 |
|-----------|------------|------|
| /login | 登录页 | meta.title |

页面中文名优先级：`meta.title` > 菜单名 > 页面标题 > 目录名

## 5. 表单字段

| 扫描位置 | 提取内容 |
|----------|----------|
| `Form.Item label`、`el-form-item label` | 字段中文名 |
| `placeholder` | 输入提示 |
| `required`、`rules` | 必填与校验 |
| `maxlength`、`min`、`max` | 长度/范围 |
| `type`、`pattern` | 格式要求 |
| `disabled`、`:readonly` | 不可编辑条件 |

输出字段表：字段名 | 类型/格式 | 必填 | 说明 | 校验/业务规则

## 6. 列表与筛选

| 扫描位置 | 提取内容 |
|----------|----------|
| `Table columns`、`el-table-column label` | 列名 |
| 筛选区表单项 | 筛选项及可选值 |
| 分页组件 | 每页条数、跳转 |
| 空态组件 | 无数据时的展示 |

## 7. 枚举与状态

| 扫描位置 | 提取内容 |
|----------|----------|
| `*Options` 常量 | 字段 → 枚举值文案 |
| `Select.Option`、`el-option` | value 与 label 映射 |
| `render`、字典映射 | 列表中的状态展示 |
| 状态变更按钮 | 允许的状态流转 |

提取 enums 对照表（内部使用）：

```text
status: 0→在住, 1→已退租, 2→待审核
```

PRD 中写「状态为「在住」」，不写 `status=0`。

## 8. 按钮与操作

| 操作类型 | 扫描位置 |
|----------|----------|
| 提交 | `@click="handleSubmit"`、`onFinish` |
| 取消/返回 | `@click="cancel"`、`router.back` |
| 删除确认 | `MessageBox.confirm`、`Modal.confirm` |
| 批量操作 | 多选 + 批量按钮 |
| 跳转 | `router.push`、`navigate` |

记录：触发条件、确认提示、成功/失败反馈、跳转目标。

## 9. 校验与错误提示

- 前端校验：`rules` 中的 `message`
- 提交失败：`catch`、`Message.error` 文案
- 后端错误码映射（若有）：转为业务描述

## 10. 业务流程（用于 Mermaid）

识别主流程步骤：

1. 入口（谁、从哪进入）
2. 关键操作顺序
3. 分支（成功/失败/权限不足）
4. 结束状态（跳转、提示、数据变化）

用于绘制 flowchart 和 sequenceDiagram。

## 11. 异常与边界

| 场景 | 代码特征 |
|------|----------|
| 未登录访问 | 路由守卫 redirect |
| 无权限 | 403 处理、按钮隐藏 |
| 空数据 | `el-empty`、空列表 |
| 网络错误 | catch、重试按钮 |
| 重复提交 | `:loading`、防抖 |
| 并发/冲突 | 乐观锁提示、版本号 |

## 12. 开放问题

以下情况**必须**写入「开放问题」，不得编造：

- 业务规则仅在注释中模糊提及
- 状态流转不完整（缺少某些状态的入口）
- 权限规则前后端不一致
- 字段含义无法从 label/注释推断
- 外部系统交互细节不可见

## 技术栈补充

### Vue

- 路由：`src/router/`、`routes`
- 表单：`<el-form>`、`<a-form>`、`rules`
- 表格：`<el-table>`、`<a-table>`

### React

- 路由：`react-router` Route、`createBrowserRouter`
- 表单：`Form`、`Form.Item`、`antd` rules
- 表格：`Table columns`

### Java Spring

- Controller 方法映射、RequestBody 字段
- DTO/VO 字段注释
- 枚举类 `getDesc()` 或注释

分析时以**用户可见行为**为准，API 细节仅用于理解流程，不写入 PRD 正文。
