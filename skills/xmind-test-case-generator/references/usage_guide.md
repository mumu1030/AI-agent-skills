# XMind 测试用例生成工具使用指南

## 需求文档格式要求

### 推荐格式

生成器能够自动识别以下格式的需求文档：

```
2.1 用户信息展示
2.1.1 基础信息
头像设置
上传规则：支持JPG/PNG格式，大小≤2MB
裁剪功能：提供圆形裁剪框
默认逻辑：未上传头像时显示默认头像

2.1.2 昵称设置
昵称规则：1-20字符，禁止特殊符号
重名处理：提示用户修改昵称
```

### 格式说明

- **章节编号**：使用数字编号，如 `2.1`, `2.1.1` 等
- **功能点**：每个功能点单独一行
- **规则描述**：功能点下的详细规则，可以多行

## 测试用例设计原则

### 正向用例设计

正向用例应覆盖：
- 正常业务流程
- 标准操作流程
- 预期成功场景

示例：
- 正常登录
- 上传符合要求的文件
- 输入有效数据

### 负向用例设计

负向用例应覆盖：
- 错误输入
- 无效操作
- 违反规则的操作

示例：
- 输入错误密码
- 上传不支持的文件格式
- 输入超出限制的数据

### 边界值用例设计

边界值用例应覆盖：
- 最小值
- 最大值
- 临界值

示例：
- 输入1个字符（最小值）
- 输入20个字符（最大值）
- 输入正好100字（限制值）

### 异常用例设计

异常用例应覆盖：
- 网络异常
- 系统异常
- 数据异常

示例：
- 网络断开时的操作
- 服务器错误时的处理
- 数据格式错误时的处理

## 工作流程

### 1. 分析需求文档

- 识别功能模块
- 提取功能点
- 理解业务规则

### 2. 设计测试用例结构

- 为每个功能点创建测试用例分类
- 规划正向、负向、边界值、异常用例
- 确定用例优先级

### 3. 生成 XMind 文件

使用生成器脚本：
```python
from scripts.xmind_generator import XMindGenerator

generator = XMindGenerator()
# ... 构建结构 ...
generator.generate_xmind("output.xmind", "测试用例", structure)
```

### 4. 完善测试用例

在 XMind 中打开生成的文件：
- 添加具体的测试步骤
- 补充预期结果
- 标记优先级
- 添加备注说明

## 最佳实践

### 结构清晰

- 保持层级不超过4层
- 每个功能点的测试用例分类保持一致
- 使用清晰的命名

### 覆盖全面

- 确保每个功能点都有正向、负向、边界值用例
- 关键功能增加异常用例
- 重要业务规则单独设计用例

### 可维护性

- 使用统一的命名规范
- 为复杂用例添加备注
- 定期更新和维护

## 配置系统

### 使用默认配置（通用规则）

如果不传入配置，生成器会使用默认的通用规则：

```python
from xmind_generator import XMindGenerator

generator = XMindGenerator()  # 使用默认通用规则
```

### 自定义配置

如果需要针对特定业务场景定制规则，可以传入配置字典：

```python
from xmind_generator import XMindGenerator

# 自定义配置
custom_config = {
    'precondition_rules': {
        'default': '系统正常运行',
        'keywords': {
            '购物车': '用户已登录，购物车中有商品',
            '支付': '用户已登录，已确认订单信息，准备支付',
            # 添加更多关键词匹配规则...
        }
    },
    'test_step_rules': {
        '正向用例': lambda name, parent: f"1. 进入相关功能页面\n2. 执行操作：{name}\n3. 验证操作成功",
        # 自定义其他测试类型的规则...
    },
    'expected_result_rules': {
        '正向用例': lambda name, parent: f"操作成功，{name}功能正常，符合预期",
        # 自定义其他测试类型的规则...
    }
}

generator = XMindGenerator(config=custom_config)
```

### 配置说明

- **precondition_rules**: 前置条件规则
  - `default`: 默认前置条件（当没有匹配到关键词时使用）
  - `keywords`: 关键词匹配字典，键为关键词，值为对应的前置条件

- **test_step_rules**: 测试步骤规则
  - 键为测试类型（"正向用例"、"负向用例"、"边界值用例"、"异常用例"）
  - 值为函数或字符串模板，函数接收 `(case_name, parent_title)` 参数

- **expected_result_rules**: 预期结果规则
  - 键为测试类型
  - 值为函数或字符串模板，函数接收 `(case_name, parent_title)` 参数

更多配置示例请参考 `references/config_example.py`。

## 常见问题

### Q: 生成的文件无法在 XMind 中打开？

A: 确保使用的是 XMind Zen 或更新版本的 XMind。如果仍有问题，检查 content.json 格式是否正确。

### Q: 如何自定义测试用例分类？

A: 修改 `create_test_cases_structure` 方法中的分类列表，或手动构建结构。

### Q: 如何为特定业务场景定制规则？

A: 使用配置系统，传入 `config` 参数自定义规则。参考 `references/config_example.py` 中的示例。

### Q: 支持添加图片或附件吗？

A: 当前版本不支持，但可以在 XMind 中打开文件后手动添加。
